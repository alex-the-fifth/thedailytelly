# Security

This early release targets the current main branch. There is no legacy release
support series or guaranteed response time.

Use GitHub's **Report a vulnerability** once enabled on the repository. Never post
exploit details, credentials, child activity, or household data in public issues.
If private reporting is not enabled, ask for a private contact without sensitive
details. Include affected version, impact, and a minimal synthetic reproduction.
Do not probe someone else's deployment.

Use HTTPS, Secure cookies, verified adult email, independently revocable device
tokens, restricted files, and secure backups. The Daily Telly is a curated interface, not moderation, a
sandbox, or a kiosk. See [privacy](docs/privacy.md) and [deployment](docs/deployment.md).
