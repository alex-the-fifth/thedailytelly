# Launch policy review

This is a child-facing YouTube-embedding service with adult-managed accounts.
Parent-only signup does not remove the need to assess child-directed obligations.

Official sources:
- [YouTube API developer policies](https://developers.google.com/youtube/terms/developer-policies)
- [Embedding help and child-directed designation](https://support.google.com/youtube/answer/171780)
- [Required player functionality](https://developers.google.com/youtube/terms/required-minimum-functionality)
- [Google privacy policy](https://policies.google.com/privacy)

The platform version removes the inherited player-covering overlay, codec
interception, and caption suppression. Standard YouTube controls/links/branding
remain visible. Privacy-enhanced embeds can still show ads and process data.
Daily Telly's no-ad/no-tracking commitments apply to its own platform, not Google.

Before launch, complete the applicable child-directed self-designation and API
review, review local privacy/child-safety requirements with an appropriate adviser,
publish an accurate operator/provider notice, and verify retention/deletion.
No claim of YouTube approval or legal compliance is made by this implementation.
